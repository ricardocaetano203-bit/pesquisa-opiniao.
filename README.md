## Descrição do Projeto
Programa desenvolvido em Python utilizando estruturas de repetição (`for`) e de decisão (`if-elif-else`) para automatizar a recolha e análise do grau de satisfação dos clientes da empresa de marketing TudoWeb.

## Requisitos Atendidos
- Coleta de dados individuais (nome, idade e código de opinião: 1 para Excelente, 2 para Bom e 3 para Ruim).
- Validação inicial efetuada com 10 entrevistados.
- Execução oficial efetuada com 50 entrevistados.
- Contagem e exibição final das quantidades de respostas **EXCELENTE** e **RUIM**.

## Tecnologias Utilizadas
- **Linguagem:** Python
- **Ambiente:** Visual Studio Code / Windows Terminal
- **Controlo de Versão:** Git e GitHub

## Como Executar
1. Certifique-se de que tem o Python instalado no seu computador.
2. Descarregue o ficheiro `pesquisa-opiniao.py`.
3. Abra o terminal na pasta do ficheiro e execute o comando:
   ```bash
   python pesquisa-opiniao.py
