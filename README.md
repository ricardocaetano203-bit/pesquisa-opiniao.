Projeto desenvolvido em Python no âmbito da **Agenda 08 - Desenvolvimento de Sistemas I** (ETECAP).

## Descrição do Projeto
Programa desenvolvido em Python utilizando estruturas de repetição (`for` e `while`) e de decisão (`if-elif-else`) para automatizar a recolha, validação e análise do grau de satisfação dos clientes da empresa de marketing **TudoWeb**.

## Requisitos Atendidos
- Coleta de dados individuais (nome, idade e código de opinião: 1 para Excelente, 2 para Bom e 3 para Ruim).
- **Validação de Entrada:** Uso de laço `while` para impedir entradas incorretas e garantir a integridade dos dados da pesquisa.
- Validação inicial efetuada com 10 entrevistados.
- Execução oficial efetuada com 50 entrevistados.
- Contagem e exibição final das quantidades de respostas **EXCELENTE** e **RUIM**.

## Tecnologias Utilizadas
- **Linguagem:** Python
- **Ambiente:** Visual Studio Code / Windows Terminal
- **Controle de Versão:** Git e GitHub
